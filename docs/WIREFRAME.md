# TWO SCRIPTS, ONE CANVAS 화면 구성 (v0.1)

모바일(390px 기준)을 먼저 설계하고, 데스크톱은 같은 구성을 3단으로 펼친다.
모든 문구는 `繁體中文 / 한국어` 병기다. 아래 중국어 문구는 초안이며 대만 원어민 검수 전이다.
와이어프레임에서는 한국어 병기를 줄 아래에 표기했다. 실제로는 중국어가 먼저, 한국어는 작고 연한 회색이다.

## 화면 목록
| ID | 화면 | 목적 |
|---|---|---|
| S1 | 홈 | 서비스 소개, 예시, 모드 선택 |
| S2 | 모드 A 에디터 (한자 채우기) | 번체자를 입력하고 한글로 채움 |
| S3 | 모드 B 에디터 (자유 캔버스) | 자모를 직접 배치 |
| S4 | 저장·공유 시트 | 비율, 워터마크, 저장, 공유 |

## 이동 흐름
```
S1 홈 ──예시 카드──▶ S2 또는 S3 (예시 설정이 채워진 상태)
S1 홈 ──모드 선택──▶ S2 또는 S3
S2 / S3 ──저장·공유──▶ S4 (시트)
S2 ◀──▶ S3  상단 탭으로 전환 (각 모드는 세션 동안 자기 작업을 유지)
```

## S1 홈 (모바일)
```
──────────────────────────────
 TWO SCRIPTS, ONE CANVAS            ← 헤더: 로고만, 언어 토글 없음
──────────────────────────────
 [ 히어로 이미지 ]
   愛를 사랑 / ㅅㅏㄹㅏㅇ로 채운 이미지
   (흰 배경 · 검은 글자, 정사각형)

 用韓文字母，寫出漢字
 한글 자모로 한자를 쓰다

 [ 開始 / 시작 ]                    ← 검정 채움 버튼, 모드 선택으로 스크롤
──────────────────────────────
 範例 / 예시
 [ 愛 ] [ 福 ]                      ← 2열 카드, 가로 스크롤 없이 2×2
 [ 台灣 ] [ 夢 ]
   카드: 결과 이미지 + 한 줄 설명 + 사용한 자모
         [ 用這個開始 / 이 예시로 시작 ]
──────────────────────────────
 選擇模式 / 모드 선택
 ┌ A  填字 / 한자 채우기
 │   輸入漢字，用韓文填滿
 │   한자를 입력하고 한글로 채우기
 └ [ 進入 / 들어가기 ]
 ┌ B  自由創作 / 자유 캔버스
 │   用字母一個一個拼出圖形
 │   자모를 하나씩 조립하기
 └ [ 進入 / 들어가기 ]
──────────────────────────────
 PB03                               ← 푸터: 워터마크명, 폰트 라이선스 안내
```
- 히어로 이미지가 곧 가장 큰 예시다. 설명 문장은 두 줄 이내로 한다.
- 데스크톱: 히어로(좌 이미지 / 우 문구와 버튼) → 예시 4열 → 모드 2열.

## S2 모드 A 에디터 (한자 채우기, 모바일)
```
──────────────────────────────
 ←   [ A 填字 | B 自由創作 ]   ⓘ     ← 상단: 뒤로, 모드 탭, 도움말
──────────────────────────────
 ┌────────────────────────────┐
 │                            │
 │        캔버스 (1:1)         │       ← 기본으로 愛 + 사랑이 채워진 상태
 │                            │         (빈 화면으로 시작하지 않는다)
 └────────────────────────────┘
 [ 1:1 | 4:5 ]
──────────────────────────────
 [ 漢字 / 한자 | 填充 / 채우기 | 顏色 / 색상 ]   ← 탭 3개
 ┌ 漢字 탭
 │  漢字 입력 [ 愛        ]  (1~4자)
 │  字體 [ 黑體 / 고딕 | 明體 / 명조 ]
 ├ 填充 탭
 │  材料 [ 單字 / 단어 | 字母 / 자모 | 混合 / 혼합 ]
 │  단어 입력 [ 사랑      ]
 │  자모 선택 [ㄱ][ㄴ]…[ㅣ]  (선택한 자모만 사용)
 │  密度 / 밀도  ──●────
 │  大小 / 크기  [ 均一 / 균일 | 隨機 / 랜덤 ]
 │  旋轉 / 회전  [ 無 / 없음 | 隨機 / 랜덤 ]
 └ 顏色 탭
    字色 / 글자색  ● ● ● ● ● [ + ]
    底色 / 배경색  ● ● ● ● ● [ + ]
    [ 反轉 / 뒤집기 ]   外框 / 외곽선 [ 끔 | 켬 ]
──────────────────────────────
 [ 儲存 / 저장 ]   [ 分享 / 공유 ]    ← 하단 고정 바
```
- 한자를 입력하면 마스크가 즉시 갱신된다. 폰트 로딩 중에는 캔버스에 로딩 표시를 한다.
- 입력이 번체자 외 문자일 때(간체, 영문 등)는 입력창 아래에 안내를 보여준다.
- 조절 항목은 탭으로 나눈다. 한 화면에 모두 펼치지 않는다.

## S3 모드 B 에디터 (자유 캔버스, 모바일)
```
──────────────────────────────
 ←   [ A 填字 | B 自由創作 ]   ⓘ
──────────────────────────────
 [ ↶ ][ ↷ ]   [ 複製 ][ 刪除 ][ 翻轉 ][ 上移 ][ 下移 ]   ← 도구줄 (가로 스크롤)
 ┌────────────────────────────┐
 │                            │
 │        캔버스 (1:1)         │       ← 빈 상태: 중앙에 안내 문구
 │      點選字母加入            │         "아래 자모를 눌러 추가하세요"
 │                            │
 └────────────────────────────┘
 [ 1:1 | 4:5 ]   背景 / 배경 ●
──────────────────────────────
 [ 子音 / 자음 | 母音 / 모음 ]       ← 팔레트 탭
 ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ              ← 2줄 그리드, 7열
 ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ
──────────────────────────────
 선택한 자모 속성 (선택 시에만 표시)
 色 ● ● ● ● ●   大小 ──●──   旋轉 ──●──
──────────────────────────────
 [ 儲存 / 저장 ]   [ 分享 / 공유 ]
```
- 자모를 누르면 캔버스 중앙에 추가되고, 바로 선택 상태가 된다.
- 선택된 자모에는 이동·회전·크기 핸들이 붙는다.
- 팔레트의 자모를 길게 누르면 이름 툴팁(ㅅ 시옷 / siot)이 뜬다.
- 두 번째 줄 이후 화면이 좁으면 팔레트가 캔버스를 가리지 않도록 높이를 고정한다.

## S4 저장·공유 시트
```
──────────────────────────────
 ✕                       儲存與分享 / 저장·공유
 ┌────────────────────────────┐
 │       결과 미리보기          │
 └────────────────────────────┘
 比例 / 비율   [ 1:1 | 4:5 ]
 浮水印 / 워터마크 PB03   [ 켬 ]
 [ 儲存圖片 / 이미지 저장 ]        ← 검정 채움
 [ 分享 / 공유 ]                   ← Web Share API (모바일)
 [ 複製連結 / 링크 복사 ]           ← 사이트 주소 복사 (데스크톱 대체)
 LINE · Instagram · Facebook · Threads
 저장 후 앱에서 업로드하세요
──────────────────────────────
```
- 모바일은 아래에서 올라오는 시트, 데스크톱은 중앙 모달.
- Web Share API가 지원되지 않는 브라우저에서는 공유 버튼을 숨기고 저장과 링크 복사만 보여준다.

## 데스크톱 레이아웃 (S2, S3 공통)
```
──────────────────────────────────────────────────────────
 TWO SCRIPTS, ONE CANVAS            [ A 填字 | B 自由創作 ]
──────────────────────────────────────────────────────────
  좌 (260px)       │       중앙 캔버스        │  우 (280px)
  S2: 漢字·填充 입력 │                         │  S2: 顏色
  S3: 子音/母音 팔레트│     1:1 / 4:5 미리보기    │  S3: 선택 자모 속성
                   │                         │
──────────────────────────────────────────────────────────
                                   [ 儲存 / 저장 ] [ 分享 / 공유 ]
```

## 공통 UI 규칙
- 버튼 3종: 채움(검정, 주요 동작) / 외곽선(1px, 보조) / 텍스트(보조 링크).
- 선택 상태는 검정 채움 또는 2px 외곽선으로 표시한다. 색으로만 구분하지 않는다.
- 터치 영역은 최소 44px로 하고, 병기 버튼은 두 줄을 허용한다.
- 모든 아이콘 버튼에는 이름(병기)을 툴팁 또는 보조 텍스트로 붙인다.

## 확인이 필요한 사항
1. 모드 A에서 입력 가능한 글자 수(1~4자)와 기본 예시(愛 + 사랑)가 맞는지
2. S1 히어로 문구 초안(用韓文字母，寫出漢字 / 한글 자모로 한자를 쓰다)을 쓸지
3. 첫 방문 시 튜토리얼 오버레이를 둘지, 예시와 기본값만으로 갈지
