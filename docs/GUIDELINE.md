# TWO SCRIPTS, ONE CANVAS 가이드라인 (v0.3)

## 1. 한 줄 정의
한글 자모 24종으로 번체자(繁體字) 형태의 타이포그래피를 만들고, 이미지로 저장하거나 SNS에 공유하는 체험형 웹사이트.

- 프로젝트 이름: **TWO SCRIPTS, ONE CANVAS**
- 이미지 워터마크: **PB03**

## 2. 대상과 언어
- 주 타겟: 대만인. 보조 타겟: 한국인.
- 언어 토글은 두지 않는다. **사이트 안의 모든 문구를 한국어와 중국어(繁體中文)로 병기한다.**
- 병기 규칙
  - 형식: 한 요소 안에 두 언어를 함께 쓴다. 버튼과 라벨은 `儲存 / 저장`처럼 한 줄 또는 두 줄로 쓰고, 긴 안내문은 중국어 한 줄과 한국어 한 줄로 나눈다.
  - 순서: 주 타겟이 대만인이므로 繁體中文을 먼저, 한국어를 그다음에 둔다. 한국어는 한 단계 작은 크기와 연한 회색으로 둔다.
  - 문구는 짧게 쓴다. 병기하면 길이가 두 배가 되므로 버튼은 2~4자 단어 위주로 쓴다.
  - 두 언어를 합친 길이로 레이아웃이 깨지지 않게 한다. 버튼은 줄바꿈을 허용하고 최소 터치 영역 44px을 지킨다.
  - 繁體中文 문구는 대만 표현으로 쓴다 (예: 儲存, 分享, 復原). 중국 본토식 표현(保存, 视频 등)과 간체자는 쓰지 않는다. 출시 전에 대만 원어민이 검수한다.
- 자모를 누르면 이름을 툴팁으로 보여준다 (예: ㅅ 시옷 / siot). 한국어를 모르는 이용자를 위한 장치다.

## 3. 핵심 경험
**"내가 아는 한자를, 한글 자모로 다시 만든다."**
- 흐름: 예시 → 만들기 → 저장·공유.
- 첫 화면에서 설명 없이 바로 시작할 수 있어야 한다.

## 4. 예시 (온보딩)
| 유형 | 설명 | 예시 |
|---|---|---|
| A. 한자 채우기 | 한자 형태 안쪽을 한글 단어와 자모로 채운다 | 愛 ← `사랑`, `ㅅㅏㄹㅏㅇ` / 福 ← `복` / 台灣 ← `대만` |
| B. 자모로 조립 | 자모 조각으로 글자나 그림 자체를 만든다 | 자모로 만든 글자, ㅇ으로 만든 얼굴 |

- 예시는 3~4개로 제한한다. 카드마다 결과 이미지, 한 줄 설명, 사용한 자모를 보여준다.
- 대만 이용자에게 친숙한 글자를 우선 쓴다 (愛, 福, 夢, 台 등).
- 예시 카드의 "이 예시로 시작" 버튼으로 해당 모드와 설정이 채워진 상태로 진입한다.

## 5. 모드
두 모드는 1차에서 **완전히 분리**한다. 한쪽 결과를 다른 쪽으로 보내 편집하는 기능은 없다.

### 모드 A. 한자 채우기 (마스크 모드)
- 입력: 번체자 1~4자. 글자 수가 많으면 마스크가 작아지므로 안내 문구를 보여준다.
- 마스크 생성: 번체자 폰트로 오프스크린 캔버스에 글자를 렌더하고, 그 픽셀 영역을 마스크로 쓴다. 한자 형태를 따로 그릴 필요가 없다.
- 마스크 서체: 고딕(굵음) / 명조 2종. 획이 굵을수록 채울 공간이 넓다.
- 채우기 재료: 한글 단어 직접 입력, 자모 24종 선택, 혼합.
- 조절 항목: 밀도, 글자 크기(균일/랜덤), 회전(없음/랜덤), 마스크 외곽선 표시 여부, 채움 색상, 배경색.
- 1차 구현은 마스크 내부 격자·랜덤 배치. 획 방향을 따라 배치하는 기능은 이후 단계.

### 모드 B. 자유 캔버스
- 자모 팔레트 24종(자음 14: ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ / 모음 10: ㅏㅑㅓㅕㅗㅛㅜㅠㅡㅣ).
- 조작: 추가, 이동, 크기, 회전, 좌우반전, 복제, 삭제, 앞뒤 순서, 실행 취소/다시 실행.
- 자모 하나하나에 색상을 지정할 수 있다.
- 보조: 스냅과 가이드선(선택).

## 6. 폰트 방침
- 자모와 한글은 폰트로 렌더한다. 직접 그린 글리프는 만들지 않는다.
- **이미지 저장·SNS 공유가 핵심 기능이므로 라이선스가 명확한 오픈 폰트만 쓴다** (SIL OFL 등 상업 이용과 이미지 출력이 허용되는 것).
- 후보:
  - 한글: Noto Sans KR, Noto Serif KR
  - 번체자 마스크: Noto Sans TC, Noto Serif TC
- 한자 폰트는 용량이 크므로 입력된 글자만 서브셋으로 불러온다. 저장 직전에는 `document.fonts.load()`로 폰트 로딩 완료를 확인한다.
- 폰트를 하나 추가하기 전에 라이선스 문서를 확인하고 이 문서에 기록한다.
- 1차 구현 기록
  | 용도 | 폰트 / 굵기 | 라이선스 |
  |---|---|---|
  | 마스크 黑體 | Noto Sans TC 700 (900은 愛처럼 획이 많은 글자의 빈 공간이 막혀 형태가 뭉개짐) | OFL 1.1 |
  | 마스크 明體 | Noto Serif TC 900 | OFL 1.1 |
  | 채우기 한글 | Noto Sans KR 900 | OFL 1.1 |
  | 자유 캔버스 자모, UI 한글 | Noto Sans KR 700 | OFL 1.1 |
  | UI 중국어 | Noto Sans TC 400/700 | OFL 1.1 |
  | 캔버스 편집 라이브러리 | Konva 10.10.0 (저장소에 포함) | MIT |

## 7. 저장·공유
- PNG 저장: 1:1(1080×1080), 4:5(1080×1350) 둘 다 제공.
- 공유: 모바일은 Web Share API(파일 공유). 데스크톱은 저장과 링크 복사.
- 대만에서 쓰는 LINE, Instagram, Facebook, Threads를 공유 안내 문구에 포함한다. 이미지 직접 게시 API는 없으므로 "저장 후 업로드" 흐름을 병행한다.
- 워터마크 `PB03`은 이미지 하단 모서리에 작게 넣는다. 기본값은 켜짐이고, 이용자가 끌 수 있다.
- 워터마크는 작품 색상과 배경색에 관계없이 읽히도록 배경 밝기에 따라 흑/백을 자동으로 바꾼다.

## 8. 디자인
- 사이트 UI는 블랙 앤 화이트의 깔끔한 레이아웃. 장식은 최소화하고 작업물이 주인공이 되게 한다.
- UI 팔레트: `#000` / `#fff` / 회색 3단계. 색은 작품 영역 안에서만 나타난다.
- **작품 색상은 이용자가 선택할 수 있다.**
  - 글자 색과 배경색을 각각 고른다.
  - 기본값은 흰 배경·검은 글자이고, 검은 배경·흰 글자로 한 번에 뒤집는 버튼을 둔다.
  - 프리셋 색상(흑, 백, 회색, 소수의 포인트 컬러)과 직접 선택을 함께 제공한다. 포인트 컬러는 UI의 흑백과 구분되게 채도가 있는 색으로 한다.
- 여백과 그리드를 일정하게 유지하고, 선은 1px 헤어라인을 기본으로 한다.
- UI 폰트는 Noto Sans TC/KR 하나만 쓴다. 로고 `TWO SCRIPTS, ONE CANVAS`는 영문 대문자로 표기한다.
- 레이아웃: 모바일은 상단 캔버스, 하단 컨트롤. 데스크톱은 좌측 팔레트, 중앙 캔버스, 우측 속성.

## 9. 기술 방향 (제안)
- 정적 사이트(서버 없음), 브라우저에서 모두 처리. 모바일 우선 반응형.
- 캔버스: Konva.js (모드 B의 조작 핸들 기본 제공). 모드 A의 마스크 샘플링은 Canvas 2D `getImageData`로 처리.
- 접근성: 키보드 조작, UI 명도 대비, 터치 영역 최소 44px.
